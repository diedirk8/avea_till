# Vision

## Why Avea Exists

Avea exists to build software that people enjoy using.

Too much business software is complicated, slow and requires training before users become productive.

Our goal is different.

Software should adapt to the business.
The business should never have to adapt to the software.

---

# Our Mission

Build software that feels obvious.

If a user has to ask:

> "What do I do here?"

then we have failed.

Every screen should guide the user naturally.

The correct action should always feel like the next obvious step.

---

# Design Philosophy

## Simplicity First

Every feature should make the software easier to use.

Complexity is only acceptable when it removes complexity from the user's experience.

---

## One Purpose Per Screen

Every screen should answer one question.

Every button should have one purpose.

Every workflow should feel natural.

---

## Build on Proven Foundations

Whenever possible, extend existing platforms instead of rebuilding them.

Reuse existing functionality.

Avoid duplicating business logic.

Build only what creates value.

---

## Solve Real Problems

Features are never added because they are possible.

Features are added because they solve a real business problem.

If a feature does not make someone's job easier, it probably does not belong in the product.

---

## Professional Quality

Every module should feel like it belongs in the platform.

Users should not be able to tell where Odoo ends and Avea begins.

---

## Fast

Users should never wait unnecessarily.

Software should respond immediately.

Performance is a feature.

---

## Reliable

Businesses depend on our software.

Reliability is more important than adding new features.

Every release should improve stability.

---

# Development Principles

Before implementing a feature, ask:

- Does this solve a real problem?
- Is there a simpler solution?
- Can Odoo already do this?
- Will this still make sense in five years?
- Would a first-time user understand it immediately?

If the answer to any of these is "No", rethink the design.

---

# Long-Term Vision

Avea is not a collection of modules.

It is a suite of software built around one philosophy:

Simple.
Reliable.
Professional.

Every module should follow the same principles, whether it is built for retail, construction, manufacturing or any other industry.

Users should trust that every Avea product will be intuitive, dependable and designed around how people actually work.
